### מבנה התיקיות המוצע

המבנה מניח את השילוב שמומלץ בסעיף הטכנולוגיות, Next.js עם Payload CMS **\[המלצה\]**. אם תיבחר טכנולוגיה אחרת, החלוקה העקרונית נשארת זהה.

```

    api/                    ← טפסים, ובעתיד הזמנות ותשלומים
  components/
    layout/                 ← Header, Footer, MobileMenu, WhatsAppButton, StickyCTA
    blocks/                 ← Hero, TextImage, Cards, TripSummary, EventList, Gallery,
                              Video, Testimonials, FAQ, CTA, Form, Social
    ui/                     ← כפתורים, כרטיסים, תוויות ושדות
  cms/
    collections/            ← Pages, Trips, Events, Parashot, Lessons,
                              Testimonials, Team, Media, Users
    globals/                ← SiteSettings (פרטי קשר ורשתות), Navigation
  features/
    booking/                ← שמור למערכת ההזמנות, ריק בשלב 1
  lib/                      ← עזרים: SEO, עיצוב תאריכים עבריים, וואטסאפ
  styles/                   ← צבעים, גופנים ומרווחים (Design tokens)
```
